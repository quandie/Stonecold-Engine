# Stonecold Engine
Stonecold Engine made in Stonecold: The Heist, which used in other quandie's (and maybe others) roblox projects.
### Finished by ~60%

## Features:
- Downing system
- Weapon + Viewmodel system
- Inventory system
- HUD
  - Health
  - Armour
  - Current Ammo/Reserve Ammo
  - Equipment
  - Inventory
  - Objective
